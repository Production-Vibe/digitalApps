Этап: проверка перестройки флоу на канон `WorkOrders`/`Transitions`/`ClosedOrders`/`Employees`
(ADR-003, вариант A) сквозным E2E-тестом на активном `/exec`.

## Что сделано

- Листы подготовлены вручную (Employees/Transitions/ClosedOrders + колонка
  `Причина доработки` в WorkOrders) и задеплоен новый деплой.
- Написан `tests/e2e/test_bizcycle.py` — единый сквозной цикл с переключением ролей
  в одном Playwright-процессе: shift → operator → otk → (rework) с прямой навигацией
  `?page=<role-app>&name=<ФИО>`.
- Smoke-регрессия всех ролей на новом URL (вход через форму) — 16/16 PASS.
- Полный бизнес-цикл — 24/24 PASS.

## Ход цикла (что проверено)

1. Оператор имеет открытую смену на станке (переиспользована).
2. Shift выдаёт наряд из запуска «К запуску» (остаток 12 → 8 после прогонов).
3. Оператор принимает наряд (created → in_progress) и сохраняет переход
   (→ waiting_otk).
4. ОТК видит наряд в очереди «Ждут ОТК»; «Проверить переход» (Переход 5 проверен);
   «Закрыть наряд» (→ `ClosedOrders`); наряд исчезает из очереди.
5. Оператор на вкладке «Закрытые» видит наряд и карточку «✅ Итоги ОТК»
   (Принято/Брак/Кем закрыт/Дата).
6. Второй наряд: ОТК возвращает на доработку с причиной (→ rework), причина
   видна в «Доработка»; оператор вносит доработку (→ waiting_otk); ОТК снова
   видит наряд, проверяет переход и закрывает.

## Проблемы, найденные и устранённые по ходу

| Проблема | Причина | Решение |
|---|---|---|
| toast «Отказано: проверять переходы может только ОТК» при визуально корректном входе | ФИО в `Employees` — «Сидоров С. С.» (с пробелами), а тест передавал «Сидоров С.С.», и `isRole` сверяет по ФИО | Тестовые креды теперь используют фактические ФИО из `Employees` (`tests/e2e/config.py`) |
| strict mode violation: 2 кнопки «Проверить» у наряда | после rework у наряда два перехода → две строки | клик `.first` |
| карточка «Итоги ОТК» не находилась | `renderCurrentNaryad` рендерится асинхронно (`google.script.run`), тест читал `#current-content` до заполнения | поллинг до появления «Итоги ОТК»/«закрыт» |
| строка запуска могла быть скрытой | клик выполнялся по кнопке «Выдать» без `data-id` | клик по `<tr>`, ожидание оператора в `#activeOps` |
