# Этап 12 — Web Push уведомления (Фаза 2 уведомлений)

Дата: 18.09.2026. Статус: реализовано, задеплоено на стенд, проверено.

## Что сделано

Web Push до phone (PWA + Service Worker + `web-push`), поверх внутренних
уведомлений (Этап 8):

1. **БД:** модель `PushSubscription` (12-я): `login`, `endpoint @unique`,
   `p256dh`, `auth`, `createdAt`, индекс `[login]`. Миграция
   `20260918043050_add_push_subscriptions` — применена к dev (MOSD) и стендовой
   `digital_narad` (через `migrate deploy` в контейнере).
2. **Сервер:**
   - `web-push` + `@types/web-push` (замечание: в `@types` только named
     exports — `import { sendNotification, setVapidDetails }`, `TTL`);
   - `lib/push.ts` — `initWebPush`/`isPushConfigured`/`dispatchPush(logins, data)`
     (TTL 86400; на 404/410 ответ push-сервиса подписка удаляется из БД);
   - `lib/notify.ts` — после записи `Notification` рассылает push адресату
     (оператор по логину; роль — по логинам роли);
   - `routes/push.routes.ts` (`/api/push`): `GET /vapid-key`, `POST /subscribe`
     (upsert, валидация https/http-localhost endpoint), `POST /unsubscribe`
     (deleteMany login+endpoint); все под `requireAuth` всех 4 ролей;
   - VAPID-ключи в `server/.env` (`VAPID_PUBLIC/PRIVATE_KEY`,
     `VAPID_SUBJECT`, `APP_URL`), генерация `npm run push:keys`.
3. **Клиент/PWA:**
   - `public/sw.js` — `push` → `showNotification`, `notificationclick` →
     фокус/переход;
   - `public/push-init.js` (`initPush` на всех 4 ролях после
     `initNotifications`): регистрация SW; при `permission === 'granted'` —
     авто-подписка (`pushManager.subscribe` + `POST /subscribe`); при
     `default` — кнопка «Разрешить уведомления» в dropdown колокольчика
     (`notifPushHeader` в `ui.js`, клик → `window.askPushPermission`);
   - `manifest.webmanifest` + иконки: author-скрипт `scripts/make-icons.ts`
     генерирует placeholder-PNG (512/192/180, `#131c30`/`#2563eb`) в
     `public/icons/`; манифест/theme-color/apple-touch подключены во всех вью
     (`operator`, `master-app`, `shift-app`, `otk-app`, `login`).

## Ограничения (не баги)

- **iOS:** Web Push доступен с iOS 16.4+ и только для PWA, установленного
  «На главный экран» (кнопка «Разрешить уведомления» — штатный путь).
- **Headless:** реальная подписка в headless-Chrome отклоняется push-сервисом;
  проверка — на реальном устройстве.
- **Приватность headless:** Chrome сообщает о недопустимости Push в
  incognito — сообщение консоли, не относится к коду.
