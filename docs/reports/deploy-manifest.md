# Манифест деплоя «ЦифровойНаряд»

> Журнал ручных деплоев (ADR-004, вариант A). Каждая строка — один деплой;
> последняя строка — текущее состояние. Заполняется **в момент фактического
> завершения деплоя** (сразу после шага «Новая версия» в редакторе), не «авансом».
> Без номера новой версии Apps Script строка не считается зафиксированной.

## Схема записи

| Дата/время | URL `/exec` (хвост) | Git-состояние (commit/tag + чистота дерева) | Изменённые модули | Номер версии Apps Script |
|---|---|---|---|---|
| `ДД.ММ.ГГГГ ЧЧ:ММ` | `AKfycbzoPmk...` | `ab12cd3` (тег `vN-этап`) + дерево чистое / есть незакоммиченные правки | `Config`, `MasterUI`, ... | `45` |
