# ADR-001: Деплой вручную, без clasp

**Статус:** Принято (действует).
**Дата:** 2026-09-02.
**Контекст:** «docs/Мастер-промпт.md», skill `digitalapps-deploy` ранее
описывали деплой через `@google/clasp` (`build.mjs` → `dist/*.gs` → `clasp push` +
`clasp deploy`). Папка `deploy/` в репозитории отсутствует, clasp не настроен,
а фактический процесс — копирование тела `modules/*.md` в редактор Apps Script
вручную.

## Решение

Деплой выполняется **только вручную**:

1. Изменить файл-модуль `modules/*.md` (весь файл — это тело, обёрток нет).
2. Проверить синтаксис:
   `node .opencode/skills/digitalapps-deploy/scripts/check-modules.js`.
3. Скопировать **весь файл целиком** в редактор Apps Script (файл с тем же
   именем) на целевой таблице (scriptId см. `docs/МАСТЕР-ДИАГНОСТИКА.md`, ШАГ 2).
4. В Apps Script: **Развернуть → Управление развертываниями → сменить версию
   активного развертывания на «Новая версия»**.
5. Согласовывать деплой с пользователем; по завершении сообщать «тестируй».

## Последствия

- Нет сборочных артефактов (`dist/`). Исходник == `.md`.
- Код-модули не зависят от clasp-ограничений на разметку и остаются
  самодостаточным JS.
- Ошибки «доехал/не доехал код» диагностируются по `docs/МАСТЕР-ДИАГНОСТИКА.md`
  (старый URL/старый deployment).
- `clasp`/`dist`/`deploy` в проекте отсутствуют и запрещены `AGENTS.md`
  (Do/Don't); skill `digitalapps-deploy` переписан под ручной процесс, проверку
  выполняет скрипт `scripts/check-modules.js`.

## Следствия для будущего

- Если позже понадобится автоматизация деплоя — потребуется новый ADR и
  фактическая настройка clasp с аккаунтом владельца таблицы. Пока не делаем.

## Связанные пути

- `AGENTS.md` — раздел «Деплой (только ручной!)».
- `docs/МАСТЕР-ДИАГНОСТИКА.md` — пошаговый возврат к рабочему состоянию.
- `.opencode/skills/digitalapps-deploy/SKILL.md` — согласован с этим решением.
- `.opencode/skills/digitalapps-deploy/scripts/check-modules.js` — синтакс-проверка модулей.
