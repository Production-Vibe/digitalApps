# Гигиена рабочего дерева

Правила чистоты рабочего дерева действуют в любой сессии — для всех агентов,
включая субагентов (подключены через `opencode.json → instructions`). Дополняют
`instructions/safety.md` (секреты, деплой, границы) и
`instructions/verification.md` (проверки, коммиты).

## Файлы и папки
- Не создавать посторонние файлы/папки в рабочем дереве — только файлы,
  входящие в задачу и являющиеся её результатом.
- Временные/scratch-файлы — только в `.artifacts/` (gitignored) или в системном
  temp; удалять их до завершения задачи.
- Не трогать файлы вне scope задачи; чужие правки — только по явному запросу.
- Сгенерированные артефакты сборки/проверок не оставлять вне gitignored-зон
  (`dist/`, логи, скриншоты, выгрузки и т.п.).

## Зависимости
- Не добавлять зависимости, не менять `package.json`/lock-файлы, если задача
  этого не требует явно.

## Перед завершением
- Выполнить `git status --short` и удалить все созданные тобой untracked-файлы,
  не являющиеся частью результата.
