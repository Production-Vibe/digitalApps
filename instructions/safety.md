# Safety — правила безопасности и ручного деплоя «ЦифровойНаряд»

Эти правила не «конвертируются» и действуют в любой сессии. Они подключены
проектом через `opencode.json → instructions`, а здесь продублированы кратко для
быстрого восприятия. Полный контракт — `AGENTS.md`.

## Секреты и сессии
- Никогда не коммитить секреты: Google-сессия в `tests/e2e/profile/`
  (`storage_state.json`), cookies и пр. исключены `.gitignore` — не добавлять
  их в staging.
- Не хардкодить API-ключи/пароли в `opencode.json` или конфигах — только env или
  исключённые файлы.

## Деплой — только ручной
- Никакого clasp, никаких скриптов деплоя, `dist/`, `deploy/`. `modules/*.md` —
  дословные `.gs`-исходники, весь файл целиком это тело.
- Деploy выполняется вручную: правка `.md` → проверка синтаксиса → копирование
  всего файла в редактор Apps Script → версия «Новая версия» `/exec`.
- Не деплоить без явного согласия пользователя и без предупреждения, что меняется.
  По завершении этапа деплоя говорить «тестируй».

## Кавычки и строки в UI-модулях (вечная загрузка)
- В inline-`<script>` UI-модулей (OperatorUI/MasterUI/ShiftUI) `\'` запрещён.
  Вместо него — HTML-сущности (`&#39;`, `&quot;`). `\'` ломает
  `runInsertedScripts` → `SyntaxError: Unexpected string` → «вечная загрузка».
- После правки UI-модуля проверять `grep \\' <модуль>` — должно быть 0 вхождений.
- Для переводов строк в JS-строках внутри `.md` писать `\\n`.

## Границы
- НЕ править сгенерированные артефакты (их нет — исходник это `.md`).
- НЕ удалять листы/функции, на которые ссылается другой модуль (кросс-ссылки
  глобальны в Apps Script).
- НЕ переименовывать файлы-модули без обновления README и роутинга `doGet`.
- Push в удалённый репозиторий — только с явного разрешения пользователя.
